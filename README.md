# cc_WebServer - 基于 C++11 的高性能 HTTP 服务器

## 项目简介

cc_WebServer 是一个基于 C++11 和 cc_muduo 网络库开发的高性能 HTTP 服务器，具有以下特点：

- 事件驱动架构，支持高并发
- 简洁的路由系统
- 内置性能监控
- 模块化设计，易于扩展

## 功能特性

### 核心功能
✔ HTTP/1.1 协议支持  
✔ 多线程处理  
✔ 路由系统  
✔ 请求解析  
✔ 响应生成  

### 扩展功能
✔ 性能监控  
✔ 静态文件服务  
✔ RESTful API 支持  

## 快速开始

### 编译项目
```bash
sudo bash autobuild.sh
```
### 运行服务器
```bash
./bin/cc_WebServer (可选参数：端口，默认2000)
 ```
## 性能指标
- 支持 10,000+ 并发连接
- 平均请求处理时间 < 1ms
- 内存占用 < 50MB
